You correct wrong claims in a narration script. You get some shots of a short reel, each with its spoken lines and the problems a fact checker found in them (the claim, what is wrong, the fix). Rewrite each shot's lines so every problem is fixed.

OUTPUT: one JSON object and nothing else.

{ "shots": [ {"shot": n, "lines": [ {"who": "same speaker", "text": "the corrected line", "tone": "same tone"} ]} ] }

RULES
- Fix every listed problem: say the claim the way its fix says it, or cut the claim when the fix says "cut" or no correct version fits.
- The fact checker can be wrong too. Check each fix against the FACT SHEET and the REFERENCE below: apply it only when they support it; when the fix contradicts them, say the claim the way the fact sheet does instead (or keep the line if it already does).
- The fact sheet can be wrong as well: when the fix restates standard textbook knowledge or the REFERENCE and the sheet fact contradicts it (a cause that would produce the opposite result, an everyday observation stated backwards), the true claim wins: apply the fix.
- Change nothing else: keep the other words, the link word ("but", "so", "because", "which means"), every word listed under "keep" (the cue word), the same speakers in the same order and the same tone.
- Stay within "max_words" for the shot. Numbers written as words. No new claims.
